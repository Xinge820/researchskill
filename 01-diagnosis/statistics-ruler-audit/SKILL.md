# 统一尺子审计

## 第一步：列表（逐条对照代码，不凭记忆）
对流程中每一处"尺度"列出：位置、公式、统计范围（单样本 / 池 / 跨批）、是否去均值、是否带可学习增益。
**一定包括 VAL 选点 / 早停的指标**——它和训练损失一样会偏向某种几何。

## 第二步：分类
- **数值类**（输入标准化、q/k 的 L2、读出 RMSNorm）：只管数值稳定，不参与坍塌判断。
- **统计类**（预测分母、能量项、SIGReg、监测指标、选点）：必须同一把尺子。

## 统一尺子（时序 CI 模型）
固定位置 p → 取本批所有窗口 × 变量 → **每个变量先减自己的均值** → 合池得 X。
X 只量"同一变量在不同时间的差异"。所有统计类量都基于 X。

## 盲区规则（来自 SADL 与实测）
- 任何**包含共享均值**的"尺度"（平均平方、RMSNorm 后的总长度），都能被"所有样本变成同一向量"满足 → 奖励坍塌。
- 下游任何**去均值/归一化**操作，都会在上游制造梯度为零的方向。
- **可学习增益 g** 可整体放大，绕开绝对值形式的能量约束；RMSNorm 下用比例形式或去掉 g。
- 归一化（RMSNorm/BN）和防坍塌**职责不同**，不能互相替代；替换时不得顺带删掉防坍塌项。
- 选 LayerNorm/RMSNorm（逐样本）而非 BN（批均值盲区 + 推理统计量漂移）。

## 第三步：逐处切换
每次只把一处切到统一尺子，按 VAL 判断。顺序：选点 → 预测分母 → SIGReg 打分 → 能量项。
