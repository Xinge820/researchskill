# 坍塌的几何诊断

## 定义
坍塌 = **不同输入被映射成分不开的表征**（嵌入失去单射、流形被折叠），或**丢掉了输入里可读出的信息**。
"谱很扁 / 前两轴占比高"本身不是坍塌：数据本身可能就是低维流形（时序常如此）。

## 必报指标（同一批留出窗、同一把尺子，见 statistics-ruler-audit）
| 指标 | 含义 | 坍塌信号 |
|---|---|---|
| 共享均值占比 = 均值能量 / 总能量 | 样本还能不能分开 | → 接近 100% |
| 去均值能量（绝对值） | 样本间差多少 | → 接近 0 |
| 固定维数留出解码 R²（如只用 2 个方向，TRAIN 选方向、VAL 测） | R 保住了多少观测信息 | 明显低于上限 |
| 解码上限：直接用真实输入解码 | 参照 | — |
| 下游 VAL（只用历史输入） | 最终验收 | 输给零预测/历史均值等朴素基线 |
| 谱（前两轴占比、有效秩、P10） | 参考 | 只作参考，不作验收 |

## 要点
- **能量和形状无法区分"新信息"与"噪声"**：同谱的两种表征，一个装信息一个装噪声，指标完全一样。所以必须配解码/下游。
- **信息不一定在方差大的方向上**：按方差选前两轴与按解码选两个方向的 R² 可能差几倍。
- **按变量拆开看**（CI 模型）：同一变量跨窗口的方差 vs 变量之间的差异；合池可能用变量间差异掩盖单变量的时间坍塌。
- **看时间**：逐轮（E0、E1、E5、E10…）测共享均值占比，定位坍塌发生的阶段，再找是哪项梯度。
- 绝对 MSE 小不代表好：同时报"模型 MSE ÷ 零预测 MSE"和历史均值基线。
