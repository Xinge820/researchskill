# 第一性原理的方法设计

## 先建模
- **时序 = 动力系统**：s_{t+1}=f(s_t)+w，变量 x^c=h_c(s)+ε。CI 编码器下 R^c_t ≈ g_c(s_t)。
- 同一变量不同时刻 = 状态在吸引子上的分布（低维流形，不应各向同性）。
- 同一时刻不同变量 = 同一状态的不同视角（只在共同可观测部分对齐，CCA 界定）。
- 线性近似 R_{t+1}≈A R_t+ε：Σ = AΣAᵀ+Q。强求 Σ=I 等于改动力学；防坍塌应约束**新息不退化**，并用自相关检验新息是否为白（区分真新信息与线性模型漏掉的规律）。

## 几何视角
- 训练放大、扭曲**初始几何**；终点由起点 + 放大方式决定。
- 尺度太小 → 起点"几乎一个点"→ 乘性增长强者愈强 → 早期折叠。解决：起点尺度对（数据驱动初始化 / LSUV），而非事后修。

## 设计检查清单
1. 这个约束在什么变换下不变？会不会被旋转 / 平移 / 放缩骗过？
2. 它在坍塌点附近的梯度是否有界且非零？（SIGReg 在近坍塌处推不动）
3. 下游有无去均值 / 归一化制造盲区？
4. 两项是否正交（如尺度项沿 X、0 次齐次的形状项与 X 正交）？
5. 请求能否被参数化执行？（见 request-vs-realized）
6. 成本是否在门槛内？
7. 是在处理原因，还是在抵消副作用（补丁）？

## 已验证的经验
- 相对 MSE（去均值方差为分母）关掉"缩小目标"作弊路径；尺度另由去均值能量项守。
- 能量（总量）与形状（标准差谱）用旋转不变的定义；形状项梯度在弱轴有界。
- 强行 64 维各向同性会填入无信息方差、丢解码信息——目标是防坍塌。
- 马氏距离按方向归一化会放大噪声 / 历史读不到的方向，需先确认这些方向可预测。
