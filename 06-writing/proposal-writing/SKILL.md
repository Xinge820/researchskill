# Proposal Writing

## Structure of a "significance and related work" section
Significance → the problems this work addresses → related work (with citations).

## Requirements
- Every claim about prior work is backed by a high-quality, recent citation.
- Each stated problem maps one-to-one to a planned piece of work; the reader should see which work answers which problem.
- No storytelling: state what each component does in the system and what verifiable gain it brings.
- Keep the topic itself central; application domains are validation settings, not the topic.

## Delivery
Write into an editable document, organized by subsection, with references listed separately.
