# 汇报方式

- **结论先行**，一句话说清"说明了什么"，再给证据。
- **说人话**：用户说"看不懂 / 太复杂"时，换成具体例子（三根箭头、0.8 拉向 0 这类数字例子），不堆术语。
- **讨论数学给形式化公式，不给代码**。
- 讨论方案时就讨论方案，不跑去讲流程。
- 表格只放关键数；标明哪些是 VAL、哪些是 TEST。
- 明确区分：已确认的 / 推测的 / 被撤回的。
- 缩写首次出现要解释（如 E0 = 训练开始前第 0 轮）。
- 回复简短；需要用户决定的，单独列出一个问题。
