# Literature Survey

## Rules
- "Survey" means find and summarize what exists. Do not substitute a design proposal.
- Prefer recent, high-quality primary sources (peer-reviewed papers, arXiv originals, official code or project pages). Every claim links to a source.
- If a source could only be partly read, say which part the summary relies on.

## Output structure
1. One-sentence answer: does this exist, and what does the mainstream do?
2. Approaches grouped by type: one-line principle, key formula, cost, source.
3. **Mapping to our problem**: which part of our system each approach corresponds to, and where the paradigms differ.
4. What the literature does not settle and must be tested by us.
5. A suggested order, clearly marked as a suggestion for the user to decide.
